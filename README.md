# AI Farm Assistant

An AI-powered digital assistant for the agriculture sector in Rwanda. Farmers type a question in English or Kinyarwanda, select their crop, and receive practical, Rwanda-specific advice — planting windows, pest management, rainfall guidance — generated by Google Gemini. Every query is stored in a local SQLite database and a live dashboard shows usage statistics.

---

## What it does

| Feature | Detail |
|---|---|
| **AI Q&A** | Sends questions to Gemini 1.5 Flash with a Rwanda-specific system prompt. Answers cover planting seasons (A/B/C), common pests, fertilizer use, and crop care. |
| **Language support** | Toggle between English and Kinyarwanda. The model replies in the chosen language. |
| **Crop context** | Maize, Beans, Coffee (Arabica), Irish Potatoes. Each crop injects relevant context into the prompt. |
| **History** | Last 10 queries shown below the dashboard, clickable to re-display the answer. |
| **Dashboard** | Two Chart.js bar charts — queries by crop and queries by language — loaded live from the `/stats` endpoint. |
| **Auth** | Single shared access code checked on every API request (header `x-access-code`). |

## Running locally

### 1. Prerequisites

- Node.js ≥ 18
- A free Google Gemini API key → [aistudio.google.com](https://aistudio.google.com/app/apikey)

### 2. Install and configure

```bash
# Clone / enter project
cd "kigali farm ass"

# Install dependencies (includes better-sqlite3, which compiles a native addon)
npm install

# Create your .env from the template
cp .env.example .env
```

Edit `.env`:

```env
GEMINI_API_KEY=AIza...your_key_here
ACCESS_CODE=farm2024          # pick any shared password
PORT=3000
```

### 3. Start

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000).

Enter the `ACCESS_CODE` you chose in the **Access Code** field, then ask a question.

## Deploying to Render

1. Push this repo to GitHub.
2. Go to [render.com](https://render.com) → **New Web Service** → connect your repo.
3. Render auto-detects `render.yaml`. Review and confirm.
4. In **Environment** → add `GEMINI_API_KEY` and `ACCESS_CODE` manually (they are marked `sync: false` for security).
5. Deploy. The persistent disk at `/data` keeps `farm.db` alive across redeploys.

> **Free tier note:** Render free web services spin down after 15 min of inactivity. The first request after sleep takes ~30 s. Upgrade to a paid instance for always-on behaviour.

## Deploying to Railway

1. Push to GitHub.
2. Go to [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo**.
3. Add environment variables: `GEMINI_API_KEY`, `ACCESS_CODE`.
4. Railway injects `PORT` automatically. `railway.toml` sets the start command.

> SQLite on Railway uses the ephemeral filesystem. For persistent data on Railway, attach a PostgreSQL plugin and swap `better-sqlite3` for `pg` — or use a volume mount if available on your plan.

## AI integration details

The backend uses `@google/generative-ai` (official Node SDK) with `gemini-1.5-flash` — Google's fastest free-tier model.

Each request builds a **system prompt** that:

- Identifies the assistant as a Rwandan agriculture expert
- Names the selected crop and provides its local context (elevation, seasons, typical pests)
- Instructs the model to answer only in the selected language
- Anchors advice to Rwanda's three agricultural seasons (A: Sep–Jan, B: Feb–Jun, C: Jul–Aug)
- Prohibits generic global advice

The user's typed question is sent as the user turn. The model's plain-text response is returned to the browser and persisted to SQLite.

**Free tier limits (as of 2025):** Gemini 1.5 Flash — 15 RPM, 1 million TPM, 1 500 RPD. Sufficient for a small community tool.

## Dashboard

The `/stats` endpoint returns `{ byCrop: [...], byLanguage: [...] }` from two `GROUP BY` SQL queries. The frontend renders these with Chart.js 4 (loaded from CDN) as responsive bar charts. Charts refresh automatically after every new query is submitted.

## Environment variables reference

| Variable | Required | Description |
|---|---|---|
| `GEMINI_API_KEY` | Yes | Google Gemini API key |
| `ACCESS_CODE` | Recommended | Shared password checked on every request. Omit to disable auth. |
| `PORT` | No | HTTP port (default `3000`) |
| `DB_PATH` | No | Path to SQLite file (default `./farm.db`) |
